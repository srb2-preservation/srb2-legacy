# SDL3_mixer

SDL3_mixer 3.2.4 builds with the same decoders on every platform: Ogg Vorbis
through libvorbis (not stb_vorbis), FLAC (dr_flac), MP3 (dr_mp3), MIDI
(timidity), WAV, AIFF, VOC, AU. GME and MOD music are played by the game
through libgme and libopenmpt, so SDL3_mixer is built without them.
(The Android build in thirdparty/SDL3_mixer has no AIFF or VOC, which
SDL3_mixer's Android.mk has no option for.)

## i686-w64-mingw32, x86_64-w64-mingw32 (Windows)

SDL3_mixer.dll, built against libs/SDL3 with Ubuntu 26.04's gcc-mingw-w64
(the toolchain the Windows CI uses), so it uses msvcrt.dll like SDL3.dll.
libogg and libvorbis are SDL3_mixer's vendored copies, linked into the DLL;
it only imports SDL3.dll, msvcrt.dll and KERNEL32.dll. The Ogg/Vorbis
licenses are next to the DLL in bin/.

To rebuild, fetch the vendored ogg and vorbis into an extracted
SDL3_mixer-3.2.4 release (external/download.sh, or git clone the
external/ogg and external/vorbis entries of its .gitmodules), then for each
triplet T, from Ubuntu 26.04 with gcc-mingw-w64, g++-mingw-w64, cmake and
ninja-build installed:

	R=<srb2-legacy>/libs/SDL3
	cmake -S SDL3_mixer-3.2.4 -B build-$T -G Ninja -DCMAKE_BUILD_TYPE=Release \
		-DCMAKE_SYSTEM_NAME=Windows -DCMAKE_SYSTEM_PROCESSOR=${T%%-*} \
		-DCMAKE_C_COMPILER=$T-gcc -DCMAKE_CXX_COMPILER=$T-g++ -DCMAKE_RC_COMPILER=$T-windres \
		-DCMAKE_FIND_ROOT_PATH="$R/$T;/usr/$T" -DCMAKE_FIND_ROOT_PATH_MODE_PROGRAM=NEVER \
		-DCMAKE_FIND_ROOT_PATH_MODE_LIBRARY=ONLY -DCMAKE_FIND_ROOT_PATH_MODE_INCLUDE=ONLY \
		-DCMAKE_FIND_ROOT_PATH_MODE_PACKAGE=ONLY -DCMAKE_PREFIX_PATH=$R/$T \
		-DCMAKE_INSTALL_PREFIX=install-$T -DCMAKE_SHARED_LINKER_FLAGS=-static-libgcc \
		-DBUILD_SHARED_LIBS=ON -DSDLMIXER_VENDORED=ON -DSDLMIXER_DEPS_SHARED=OFF \
		-DSDLMIXER_STRICT=ON -DSDLMIXER_TESTS=OFF -DSDLMIXER_EXAMPLES=OFF \
		-DSDLMIXER_VORBIS_STB=OFF -DSDLMIXER_VORBIS_VORBISFILE=ON -DSDLMIXER_VORBIS_TREMOR=OFF \
		-DSDLMIXER_FLAC_LIBFLAC=OFF -DSDLMIXER_FLAC_DRFLAC=ON \
		-DSDLMIXER_MP3_MPG123=OFF -DSDLMIXER_MP3_DRMP3=ON \
		-DSDLMIXER_MIDI_FLUIDSYNTH=OFF -DSDLMIXER_MIDI_TIMIDITY=ON \
		-DSDLMIXER_GME=OFF -DSDLMIXER_MOD=OFF -DSDLMIXER_OPUS=OFF -DSDLMIXER_WAVPACK=OFF
	cmake --build build-$T --target install

Copy bin/SDL3_mixer.dll, include/, lib/libSDL3_mixer.dll.a, lib/cmake and
lib/pkgconfig into $T/, and the licenses from share/licenses/SDL3_mixer/optional
into $T/bin. In lib/pkgconfig/sdl3-mixer.pc, set prefix=${pcfiledir}/../..
so it works from any checkout. Distributions with a UCRT-only MinGW (such as
Arch) produce a DLL that needs the Universal CRT, so build on Ubuntu.

## emscripten/libSDL3_mixer.a

Emscripten has no SDL3_mixer port, so the web build links this static
SDL3_mixer 3.2.4, built with Emscripten 7.0.0 against its sdl3 (3.4.2) and
vorbis (libvorbis 1.3.7, libogg 1.3.5) ports.
include/SDL3_mixer/SDL_mixer.h is the matching header.

Enabled decoders: Ogg Vorbis (libvorbisfile, not stb_vorbis), FLAC (dr_flac),
MP3 (dr_mp3), MIDI (timidity), WAV, AIFF, VOC, AU.
GME and MOD music are played by the game through libgme and libopenmpt.

libvorbisfile and libogg are not inside the archive; the game links them with
--use-port=vorbis (see src/web/CMakeLists.txt).

To rebuild, from an extracted SDL3_mixer-3.2.4 release:

	embuilder build sdl3 vorbis ogg
	SR=$(em-config CACHE)/sysroot
	emcmake cmake -S SDL3_mixer-3.2.4 -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
		-DCMAKE_PROJECT_INCLUDE=$SR/lib/cmake/SDL3/sdl3-config.cmake \
		-DBUILD_SHARED_LIBS=OFF -DSDLMIXER_VENDORED=OFF -DSDLMIXER_DEPS_SHARED=OFF \
		-DSDLMIXER_STRICT=ON -DSDLMIXER_TESTS=OFF -DSDLMIXER_EXAMPLES=OFF \
		-DSDLMIXER_VORBIS_STB=OFF -DSDLMIXER_VORBIS_VORBISFILE=ON -DSDLMIXER_VORBIS_TREMOR=OFF \
		-DVorbis_vorbisfile_LIBRARY=$SR/lib/wasm32-emscripten/libvorbis.a \
		-DVorbis_vorbisfile_INCLUDE_PATH=$SR/include \
		-DSDLMIXER_FLAC_LIBFLAC=OFF -DSDLMIXER_FLAC_DRFLAC=ON \
		-DSDLMIXER_MP3_MPG123=OFF -DSDLMIXER_MP3_DRMP3=ON \
		-DSDLMIXER_MIDI_FLUIDSYNTH=OFF -DSDLMIXER_MIDI_TIMIDITY=ON \
		-DSDLMIXER_GME=OFF -DSDLMIXER_MOD=OFF -DSDLMIXER_OPUS=OFF -DSDLMIXER_WAVPACK=OFF
	ninja -C build

CMAKE_PROJECT_INCLUDE loads the sdl3 port's CMake config up front: it has no
version file, so SDL3_mixer's versioned find_package(SDL3) would reject it.
